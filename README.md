# Customer Segmentation & Analytics

An end-to-end data project that segments 10,000 e-commerce customers using **K-Means Clustering** ($K=5$) and translates the clusters into actionable business insights using **MySQL**.

---

## 📁 Project Structure

```text
├── customer_data.csv                  # Raw dataset (10,000 rows × 42 columns)
├── customer_data_clustered.csv        # Processed dataset with K-Means cluster labels (48 columns)
├── Customer_Segmentation_Simple.ipynb # Jupyter Notebook: EDA, scaling, K-Means & PCA visualization
├── customer_segmentation_mysql.sql    # MySQL script: Schema, ingestion & analytical queries
├── .gitignore
└── README.md
```

### 📊 Dataset Roles
- **`customer_data.csv` (Raw Input)**: Original customer dataset used to run the Jupyter Notebook.
- **`customer_data_clustered.csv` (Model Output)**: Generated by the notebook with cluster assignments (`Cluster`, `KMeans_Segment`). Imported directly by the MySQL script for SQL analysis.

---

## ⚙️ Tech Stack & Workflow

- **Python**: `pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`
- **Database**: MySQL 8.0+

### Pipeline
1. **EDA & Preprocessing**: Cleaned data, one-hot encoded categorical variables, and normalized features using `StandardScaler`.
2. **K-Means Clustering**: Tested $K \in [2, 10]$ with the Elbow Method and Silhouette Analysis; selected **$K = 5$**.
3. **PCA Visualization**: Used 2-component PCA to visualize the 5 clusters and their centroids in 2D space.
4. **Customer Segments**: Identified 5 balanced demographic segments based on marital status & household size:
   - *Married*, *Together*, *Single*, *Divorced*, and *Widow* customers.
5. **SQL Business Analytics**: Ingested clusters into MySQL to analyze segment revenue shares and rank top spenders via `DENSE_RANK()`.

## 🚀 Quickstart

```bash

# 2. Install dependencies

# 3. Run the notebook

# 4. (Optional) Run SQL analytics in MySQL
```
